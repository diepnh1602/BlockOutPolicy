## Basis for this draft

The current project uses local PlayerPrefs profile/settings storage, local purchase inventory, Unity In-App Purchasing, and Unity LevelPlay with the Unity Ads adapter. No Firebase service is claimed in this policy. Apple-related wording applies only when an Apple build is distributed. Review the final release's ad partners and audience settings when they change.

The policy describes privacy practices; required consent controls must be implemented in the app separately.
